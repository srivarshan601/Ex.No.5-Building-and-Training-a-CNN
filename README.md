## Theory
1. Convolutional Neural Network (CNN)

A Convolutional Neural Network (CNN) is a type of deep learning model mainly designed for processing and analyzing image data. CNNs can automatically learn and extract important features from images, such as edges, shapes, textures, and complex object patterns.

Unlike traditional machine learning methods, CNN does not require manual feature extraction. The network automatically learns useful features during the training process.

A typical CNN consists of the following layers:

a) Convolutional Layer

The convolutional layer is responsible for extracting features from the input image. Filters or kernels move across the image and detect features such as:

Edges
Lines
Shapes
Textures
Object patterns

In deeper layers, the CNN learns more complex features.

b) Activation Function

An activation function introduces non-linearity into the neural network.

In this experiment, the ReLU (Rectified Linear Unit) activation function is used.

ReLU helps the model learn complex relationships and patterns from image data.

c) Pooling Layer

Pooling reduces the size of the feature maps generated by the convolutional layers.

MaxPooling selects the maximum value from a small region of the feature map.

This helps to:

Reduce computational complexity.
Reduce the number of parameters.
Retain important features.
Improve training efficiency.
d) Dropout Layer

The Dropout layer randomly disables some neurons during the training process.

This helps prevent overfitting, where the model performs very well on training data but poorly on new data.

e) Flatten Layer

The Flatten layer converts the multi-dimensional feature maps obtained from convolutional and pooling layers into a one-dimensional vector.

This vector is then passed to the fully connected layers.

f) Dense Layer

Dense layers are fully connected neural network layers.

They combine the extracted features and learn relationships between them to perform image classification.

g) Softmax Output Layer

The Softmax layer is used in the final output layer for multiclass classification.

It produces probability values for all the possible classes.

The class with the highest probability is selected as the predicted output.

CIFAR-10 DATASET

The CIFAR-10 dataset is a commonly used dataset for image classification tasks.

It contains:

60,000 colour images.
Image size: 32 × 32 pixels.
Training images: 50,000.
Testing images: 10,000.
Number of classes: 10.

The ten categories are:

Airplane, Automobile, Bird, Cat, Deer, Dog, Frog, Horse, Ship, and Truck.

Before training, the pixel values are normalized from the range 0–255 to 0–1. This improves the stability and efficiency of the training process.

The class labels are converted into one-hot encoded vectors for multiclass classification.

## WORKING PRINCIPLE

The working of the CNN model can be explained in several stages.

Step 1: Input Image

The CIFAR-10 dataset provides colour images of size 32 × 32 × 3.

The three channels represent:

Red
Green
Blue

The images are given as input to the CNN model.

Step 2: Data Preprocessing

The image pixel values are normalized by dividing them by 255.

This converts the pixel range from:

0–255 → 0–1

The class labels are also converted into one-hot encoded format.

Step 3: Feature Extraction

The convolutional layers apply filters to the input images.

The filters detect important visual features such as:

Edges
Shapes
Textures
Patterns

As the image passes through deeper convolutional layers, more complex features are extracted.

Step 4: Activation

The ReLU activation function is applied to the extracted features.

This introduces non-linearity and enables the network to learn complex image patterns.

Step 5: Pooling

MaxPooling layers reduce the size of the feature maps.

This reduces computational complexity while preserving important features.

Step 6: Dropout

Dropout layers randomly deactivate some neurons during training.

This helps reduce overfitting and improves the generalization ability of the model.

Step 7: Flattening

The extracted feature maps are converted into a one-dimensional vector using the Flatten layer.

Step 8: Classification

The flattened features are passed through Dense layers.

The final Softmax layer calculates the probability of the input image belonging to each of the ten classes.

For example:

Input Image → CNN Feature Extraction → Dense Layers → Softmax → Predicted Class

Step 9: Model Training

The model is trained using the training dataset.

During training:

The model predicts the output.
The prediction is compared with the actual label.
The loss is calculated.
The model parameters are updated using the Adam optimizer.

This process is repeated for multiple epochs.

Step 10: Testing and Prediction

After training, the model is tested using unseen test images.

The trained CNN predicts the category of each image.

For example:

Input Image → CNN Model → Probability Values → Maximum Probability → Predicted Class

## LIMITATIONS AND CHALLENGES
1. Large Amount of Training Data
CNN models often require a large amount of labelled training data to achieve good performance.

2. High Computational Requirements
Training deep CNN models requires considerable computational resources and processing time.

3. Overfitting
The model may learn the training data too closely and perform poorly on new images.

4. Hyperparameter Selection
Parameters such as the number of layers, filters, learning rate, batch size, and epochs can affect model performance.

5. Training Time
Complex CNN architectures can take a long time to train.

6. Image Quality
Poor-quality, blurred, or unusual images may affect the prediction performance of the model.

## Procedure
Step 1: Import Libraries
•	import tensorflow.keras for CNN layers and models
•	import matplotlib.pyplot for visualisation
•	to_categorical for one-hot encoding
import tensorflow as tf
from tensorflow.keras import datasets, layers, models
from tensorflow.keras.utils import to_categorica
import matplotlib.pyplot as plt
import numpy as np

Step 2: Load CIFAR-10 Dataset
•	Training Set: 50,000 images
•	Test Set: 10,000 images
•	Classes: Airplane, Automobile, Bird, Cat, Deer, Dog, Frog, Horse, Ship, Truck
(X_train, y_train), (X_test, y_test) 
=datasets.cifar10.load_data()

Step 3: Preprocess Data
•	Normalization scales pixel values to the range [0, 1], improving model stability and convergence.
•	One-hot encoding converts each label into a 10-dimensional vector for multiclass classification.
X_train = X_train.astype('float32') / 255.0X_test = X_test.astype('float32') / 255.0

y_train = to_categorical(y_train, 10)y_test = to_categorical(y_test, 10)
Step 4: Visualize Sample Images
•	Displays a 4×4 grid of sample images from the training set.
•	Each image is labeled with its corresponding class name.
class_names = ['Airplane','Automobile','Bird','Cat','Deer','Dog','Frog','Horse','Ship','Truck']
plt.figure(figsize=(10,10))for i in range(16):
    plt.subplot(4,4,i+1)
    plt.xticks([])
    plt.yticks([])
    plt.grid(False)
    plt.imshow(X_train[i])
plt.xlabel(class_names[np.argmax(y_train[i])])
plt.show()
Step 5: Build the CNN Model
•	Convolutional layers extract important spatial features from images.
•	MaxPooling reduces the feature map size and computational load.
•	Dropout helps prevent overfitting by randomly disabling neurons during training.
•	Softmax layer produces probability scores for the 10 CIFAR-10 classes.
model = models.Sequential()

model.add(layers.Conv2D(32, (3,3), activation='relu', padding='same', input_shape=(32,32,3)))model.add(layers.Conv2D(32, (3,3), activation='relu', padding='same'))model.add(layers.MaxPooling2D((2,2)))model.add(layers.Dropout(0.25))

model.add(layers.Conv2D(64, (3,3), activation='relu', padding='same'))model.add(layers.Conv2D(64, (3,3), activation='relu', padding='same'))model.add(layers.MaxPooling2D((2,2)))model.add(layers.Dropout(0.25))

model.add(layers.Conv2D(128, (3,3), activation='relu', padding='same'))model.add(layers.Conv2D(128, (3,3), activation='relu', padding='same'))model.add(layers.MaxPooling2D((2,2)))model.add(layers.Dropout(0.25))

model.add(layers.Flatten())model.add(layers.Dense(512, activation='relu'))model.add(layers.Dropout(0.5))model.add(layers.Dense(10, activation='softmax'))  
Step 6: Compile the Model
•	Optimizer: Adam provides fast and stable convergence.
•	Loss Function: Categorical cross-entropy is used for multiclass output.
•	Metrics: Accuracy helps track model performance during training.
model.compile(optimizer='adam',
              loss='categorical_crossentropy',
              metrics=['accuracy'])
model.summary()
Step 7: Train the Model
•	Epochs: 30 training cycles for learning patterns effectively.
•	Batch Size: 64 samples per batch for efficient gradient updates.
•	Validation Split: Helps monitor overfitting and generalization.
•	History Object: Stores accuracy and loss values for later visualization.
history = model.fit(X_train, y_train,
                    epochs=30,
                    batch_size=64,
                    validation_split=0.2)

Step 8: Plot Training History
•	Check for overfitting or underfitting
•	Visual representation helps debug training issues
plt.figure(figsize=(12,5))

plt.subplot(1,2,1)plt.plot(history.history['accuracy'], label='Train Accuracy')
plt.plot(history.history['val_accuracy'], label='Validation Accuracy')
plt.title('Model Accuracy')
plt.xlabel('Epoch')
plt.ylabel('Accuracy')
plt.legend()
plt.subplot(1,2,2)
plt.plot(history.history['loss'], label='Train Loss')
plt.plot(history.history['val_loss'], label='Validation Loss')
plt.title('Model Loss')
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.legend()

Step 10: Predict on Test Images
•	Use model.predict to get class probabilities

def plot_predictions(index):
    img = X_test[index]
    true_label = class_names[np.argmax(y_test[index])]
    pred_probs = model.predict(np.expand_dims(img, axis=0))
    pred_label = class_names[np.argmax(pred_probs)]
    
    plt.imshow(img)
    plt.title(f"True: {true_label} | Pred: {pred_label}")
    plt.axis('off')
    plt.show()

for i in range(5):
    plot_predictions(i)
